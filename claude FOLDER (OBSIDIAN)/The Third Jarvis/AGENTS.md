# The Third Jarvis — Agent Context

This is Thirdy's personal/business Obsidian vault (PARA-based). Any AI agent (Antigravity, Gemini CLI, Claude, Cursor, etc.) opened at this folder root should read this file first.

## Purpose
Central knowledge base and operating system for Thirdy's businesses (Franchise Brokerage PH, AutoClient, NXT Gen Hex) — principles, systems, playbooks, SOPs, templates, and active projects.

## Structure
- `00 Dashboard/` — home view, links into everything else
- `01 About Thirdy/` — identity, priorities, operating principles
- `10 Principles/` — durable rules (AI, business, marketing, money, sales)
- `20 Knowledge/` — reference notes by domain (AI, Life Coaching, Marketing, Mentorship, Sales, Strategy)
- `30 Businesses/` — one subfolder per business (AutoClient, Franchise Brokerage PH, NXT Gen Hex)
- `40 Systems/` — recurring operational systems (delivery, content, lead gen, reporting, sales pipeline)
- `50 Playbooks/` — how-to guides for repeatable outcomes
- `60 SOPs/` — step-by-step standard procedures
- `70 Templates/` — reusable note templates
- `80 Projects/` — active initiatives
- `90 Resources/` — books, courses, frameworks, prompts, AI imports
- `_inbox/` — unsorted capture, triage into the folders above

## Conventions
- Notes are Markdown (`.md`), edited in Obsidian. Preserve Obsidian `[[wikilink]]` syntax and YAML frontmatter when editing.
- Templates in `70 Templates/` are used with the Templater plugin — don't strip `<%...%>` templater syntax.
- New unsorted notes belong in `_inbox/`, not scattered into other folders.
- Keep tone and structure consistent with existing notes in a folder before adding new ones.

## Working in this vault
- Read before writing: check `00 Dashboard/Dashboard.md` and the relevant business folder under `30 Businesses/` before making changes.
- Prefer editing existing notes over creating duplicates; search first.
- Don't modify `.obsidian/` (app config) unless explicitly asked.
