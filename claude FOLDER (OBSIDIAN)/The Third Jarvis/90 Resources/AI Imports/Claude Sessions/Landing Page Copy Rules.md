# Landing Page Copy Rules

From the full landing-page rebuild (PHP 1,295 offer, navy + gold design):

- **Write at 4th-grade reading level or below.** Rebuilt page hit Flesch-Kincaid 3.6, avg sentence 9.8 words. Short words, no jargon.
- Headline pattern: "Buy the Right Franchise. Don't Lose Money on the Wrong One."
- **Every CTA must actually work** — buttons scroll to the embedded form, never `javascript:void(0)`
- Never repeat a tagline spam-style (the 8x "Your competition maybe already got this" was killed)
- Offer block: itemized inclusions, clear price card, 30-day guarantee box
- FAQ as working accordion; mobile-responsive

## Known gaps to fix before running ads

- Testimonials use initials only (J.B., A.C., M.L.) — get real names/faces
- No founder/authority "Who We Are" section yet
