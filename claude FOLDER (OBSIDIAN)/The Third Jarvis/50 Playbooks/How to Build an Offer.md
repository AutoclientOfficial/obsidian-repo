# How to Build an Offer

1. Pick the dream outcome (expansion/pipeline, never deliverables)
2. Apply the value equation: raise likelihood (proof, guarantee the pipeline), cut time delay (first win in weeks), cut effort (DFY) — [[Hormozi Offers & Value Equation]]
3. Stack: core system + bonuses + scarcity ("One Partner Per City") + urgency
4. Tier it: 3 options, middle designed to win ([[Pricing Strategy]])
5. Name it (own the category: "Growth Partner," "Investor-Ready Franchise System™")
6. Attach recurring infrastructure ([[Recurring Revenue Models]])
7. Compliance pass: no ROI guarantees ([[FBPH Contracts Compliance and Risk Controls]])
