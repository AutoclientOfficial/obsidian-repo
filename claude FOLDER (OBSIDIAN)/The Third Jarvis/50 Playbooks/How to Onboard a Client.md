# How to Onboard a Client

1. Collect onboarding payment at signing — before work starts
2. Send welcome kit + payment confirmation (Taglish, exciting-calm tone — SQOE pattern in [[FBPH Sales Scripts and Messaging Library]])
3. Run 14-slide onboarding presentation: process, expectations, responsibilities, timeline ([[FBPH Operations OS Team and Hiring]])
4. Intake: brand assets, financials (client attests accuracy — Section 3.5), access to pages/domains
5. Kick off Setup Phase Day 0–29 ([[Client Delivery System]])
6. Schedule weekly check-in + define the first visible win
