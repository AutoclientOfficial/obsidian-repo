# How to Create Content

1. Harvest ideas from real client questions and deals
2. Pick pillar + awareness stage ([[Eugene Schwartz Awareness Stages]])
3. Write hook first — 5 variants, pick one ([[Hooks & Content Frameworks]])
4. Structure: story → lesson → CTA ("Anolin Arc", [[Personal Brand Content Strategy]])
5. Taglish, short sentences, one idea
6. CTA by type: teaching = soft; offer = hard ([[Education-First Content Engine]])
7. Post per [[Content Machine]] cadence; recycle winners into reels
