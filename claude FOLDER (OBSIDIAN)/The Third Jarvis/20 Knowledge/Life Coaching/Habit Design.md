# Habit Design

Cue → Craving → Response → Reward.

- **Make it obvious**: stack on existing habits ("after morning coffee, review the pipeline")
- **Make it easy**: 2-minute version first (open the vault, write one line)
- **Make it satisfying**: track streaks; the scoreboard is the reward (fits the Sports Culture idea)
- **Environment beats willpower**: defaults, not discipline — phone away, dashboards visible
- Weekly review is the master habit: it repairs all the others ([[Weekly Review SOP]])
