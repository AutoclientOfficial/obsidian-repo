# Systems Thinking

See the machine, not the events. Ask: what structure produced this result?

- **Stocks & flows**: pipeline is a stock; leads/closes are flows — fixing conversion without lead flow (or vice versa) fails
- **Bottleneck rule (ToC)**: the system produces at the rate of its constraint; find it (usually appointment show-rate or capacity of 3–5 clients), improve only that
- **Feedback loops**: content → authority → inbound → case studies → more authority (reinforcing); burnout loop: more clients → less quality → churn (balancing — respect the capacity rule)
- If a fix requires heroics, the system is wrong — write the SOP ([[Operating Principles (Thirdy)]])
