# AIDA & PAS Frameworks

**AIDA** — Attention → Interest → Desire → Action. Classic ad/landing-page skeleton.

**PAS** — Problem → Agitate → Solution. Best for problem-aware audiences (most FBPH leads):

1. Problem: "May gustong mag-invest pero wala akong system."
2. Agitate: what it costs to stay unready — lost partners, sayang demand
3. Solution: the system (assessment → FBPH / Launch Point)

Rule: one idea, one emotion, one CTA per asset. Reading level ≤ grade 4 ([[Landing Page Copy Rules]]).
