# MCP (Model Context Protocol)

Open standard (by Anthropic) that lets AI models connect to tools and data sources — a "USB port" for AI. A server exposes tools/resources; any MCP-capable client (Claude Desktop, Cowork, others) can use them.

Relevance to us:

- Obsidian vault → MCP server = every AI chat can search/edit our knowledge base
- Client systems (CRM, Sheets, calendars) can be wired into AI workflows without custom integrations per tool
- The Jarvis vision is essentially: vault + MCP connectors + agents on top
