# Client Onboarding SOP

Trigger: contract signed.

1. [ ] Issue invoice; confirm onboarding payment received
2. [ ] Send welcome kit PDF + short Taglish welcome message
3. [ ] Create client folder + CRM record + tracker row
4. [ ] Book onboarding call; present 14-slide deck
5. [ ] Collect: logo/brand assets, financial data, page/domain access, contact list
6. [ ] Confirm offer structure + target partner profile in writing
7. [ ] Schedule media day
8. [ ] Open Setup Phase checklist (deck, landing page, CRM, scripts)

Owner: COO. SLA: kickoff within 7 days of payment.
