# Sales Call SOP

Before: review assessment answers · check BANT · prepare tier recommendation.

During: agenda + timebox → discovery ([[Discovery Questions]]) → mirror the gap back → present per [[Growth Partner Pitch Deck Structure]] → price, then silence → objections ([[Objection Handling]]) → same-day commitment step (reservation/onboarding payment).

After: log outcome in CRM same day · send recap + payment link within 2 hours · book follow-up before hanging up if not closed.
