# Weekly Review SOP

Every Friday, 30–45 min:

1. Scoreboard: leads, assessments, calls, closes, cash collected
2. Pipeline: move every deal one stage or disqualify
3. Content: last week's numbers → this week's calendar
4. Clients: each active client got a visible win? If not, why
5. Vault: file `_inbox`, upgrade any `hypothesis` notes with new evidence ([[Epistemic Status Convention]])
6. Pick ONE priority for next week
